# Project Overview

This is a full-stack web application called "Let's Cook". It consists of a React frontend and a Node.js (Express) backend.

## Frontend

The frontend is a React application built with Vite. It uses TypeScript, Tailwind CSS, and DaisyUI for styling.

### Running the Frontend

To run the frontend in development mode, use the following command:

```bash
npm run dev
```

To build the frontend for production, use the following command:

```bash
npm run build
```

## Backend

The backend is a Node.js application built with Express. It uses TypeScript and Prisma ORM to connect to a PostgreSQL database.

### Running the Backend

To run the backend in development mode, use the following command:

```bash
npm run dev
```

To build the backend for production, use the following command:

```bash
npm run build
```

To start the backend in production, use the following command:

```bash
npm run start
```

## Development Conventions

*   The project is split into two main directories: `frontend` and `backend`.
*   Both frontend and backend use TypeScript.
*   The frontend uses Tailwind CSS and DaisyUI for styling.
*   The backend uses Prisma ORM for database access.
